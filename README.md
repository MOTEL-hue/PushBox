# PushBox

**תוסף לשליפת SMS ממערכת IVR של ימות המשיח.**

***

**הוראות התקנה:**

הורידו את הקובץ ZIP, וחלצו אותו.

וודאו ששם התיקייה הינו PushBox, ושימו את התיקיה במיקום שלא ימחק.

גררו את התיקיה לעמוד התוספים של הדפדפן - וזהו, התוסף הותקן!

כעת כנסו להגדרות והגדירו את פרטי המערכת שלכם בימות המשיח.

**הוראות לקבלת טוקן:**

או מספר המערכת:סיסמא

או יצירת טוקן ייעודי דרך חומת האש של המערכת באתר ימות המשיח.
