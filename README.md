# PushBox

**תוסף לשליפת SMS ממערכת IVR של ימות המשיח.**

***

**הוראות התקנה:**

הורידו את הקובץ ושימו אותו במיקום שמור שלא ימחק בעתיד.

גררו אותו לעמוד התוספים של הדפדפן - וזהו, התוסף הותקן!

כעת כנסו להגדרות והגדירו את פרטי המערכת שלכם בימות המשיח.
