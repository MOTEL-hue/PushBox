# PushBox

**תוסף לשליפת SMS ממערכת IVR של ימות המשיח.**

***

**הוראות התקנה:**

הורידו את הקובץ ושימו אותו במיקום שמור שלא ימחק בעתיד.

גררו אותו לעמוד התוספים של הדפדפן - וזהו, התוסף הותקן!

כעת כנסו להגדרות והגדירו את פרטי המערכת שלכם בימות המשיח.

**הוראות לקבלת טוקן:**

או מספר המערכת:סיסמא

או יצירת טוקן ייעודי דרך חומת האש של המערכת באתר ימות המשיח, כך:

נכנסים לאתר [ימות המשיח](https://www.call2all.co.il/ym/index.php?view=events)

לוחצים על 'אימות קשיח' ומאמתים על פי קוד זמני למייל או לטלפון.

אחרי האימות לוחצים על מפתחות גישה, מחכים כמה שניות, ונפתחת כרטיסיה חדשה.

שם לוחצים על 'יצירת מפתח חדש', בוחרים שם (למשל: PusBox), לוחצים על שמירה ומקבלים טוקן ארוך אותו מדביקים בשדה הטוקן.
